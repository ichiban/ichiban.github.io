---
title: What's up with the name?
date: 2026-11-02T00:00:00+09:00
---

When I started my project `ichiban/prolog`, I never imagined it to reach the Prolog community, let alone be mentioned alongside implementations like [Scryer Prolog](https://www.scryer.pl/), [Clausal Prolog](https://clausal.pl/), and [Flowlog](https://chen.cat/flowlog/).
If you say "Ichiban Prolog" alongside the names of other Prolog implementations, it sounds rather egomaniacal. Let me explain what I meant by the name.

`ichiban/prolog` is a Go library rather than a standalone Prolog processor. Thus its name follows a Go library tradition.

```
Module path:
    github.com/ichiban/prolog
       
Package Name: 
    prolog
    
Repository shorthand:
    ichiban/prolog
```

So, `ichiban/prolog` simply combines the name I go by with what the library does. It was never meant to be read as the product name "Ichiban Prolog."
